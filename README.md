### ⚡ About Me

I specialize in **systems engineering**, **deterministic debugging**, and **zero-dependency developer tooling**. My open-source work focuses on pushing standard libraries and OS primitives to their limits — building reproducible, performant, and reliable command-line utilities.

- 🛠️ Creator of **120+ micro-tools and systems utilities** across networking, memory profiling, and build reproducibility.
- 🔬 Passionate about **Linux namespaces, memory graphs, concurrency anomalies**, and **binary delta algorithms**.
- 💡 Core philosophy: *High-performance, auditable, and self-contained software without external bloat.*
